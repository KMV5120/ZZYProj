## 1. 目标

把纯前端 BYOK 演示站改造成能独立运营的平台：

1. **独立账号**：邮箱验证码开放注册、登录，与学习助手账号体系隔离；
2. **服务端会话**：对话按用户持久化，换设备可续；
3. **服务端模型调用**：DeepSeek key 只在服务端，用户不可见、不可导出；
4. **配额**：每日消息数 + 每月 token 双上限，管理员可按人覆盖；
5. **管理后台**：用量看板、用户列表、禁用/启用、调额度；默认**不可读对话正文**；
6. **独立部署**：单独容器 + `/ZZYProj/` 子路径，可独立回滚、可整体摘除。

## 2. 不做什么（范围边界）

- 不改学习助手主应用代码（仅宿主机 nginx 增加转发，不属于主应用代码）；
- 不复用、不污染学习助手账号与数据；
- 不保留用户自带 API key（BYOK），不提供“填 key”入口；
- 不做支付、订阅、充值、开放 API；
- 不做多供应商（只用 DeepSeek 的 `deepseek-flash` / `deepseek-v4-pro`）；
- 不提供管理员读对话内容的接口；
- 不迁移旧 localStorage 数据（原站无真实用户数据）；
- 不重做原 UI 设计语言，只替换数据层并增加账号/配额/管理视图；
- v1 不做找回密码、账号注销、改绑邮箱（下一版再议；管理员可用 CLI 建号/禁用兜底）。

## 3. 角色与权限

| 角色 | 能做什么 | 不能做什么 |
| --- | --- | --- |
| 游客 | 查看登录页、演示模式（内置示例，不调模型） | 调模型、建会话、注册前使用 |
| 用户 | 注册/登录、会话增删查、聊天、查看本人用量 | 读写他人会话、进入管理后台 |
| 管理员 | 看用量看板/用户列表、禁用、调单人额度、提权 | 读取对话正文（API 与 UI 均不提供） |
| 服务端 | 唯一持有 DeepSeek key、SMTP 授权码、JWT 密钥 | 把上述秘密下发给前端 |

## 4. 业务断言

| ID | 断言 | 类型 | 边界/反例 | 验收 |
| --- | --- | --- | --- | --- |
| R1 | 邮箱验证码开放注册：6 位码、10 分钟有效、最多试 5 次、60 秒重发；同 IP 每日最多 10 次；密码 ≥8 位；邮箱唯一、大小写归一 | 不变式 | 重复邮箱、过期码、错码 5 次、未配置 SMTP、頻繁重发 | A1–A5 |
| R2 | 登录：邮箱+密码，签发 30 天 JWT；禁用用户拒绝；失败文案不区分“不存在/密码错” | 不变式 | 禁用、错误密码、不存在邮箱、过期 token | A6–A8 |
| R3 | 会话隔离：只能读写自己的会话；越权统一 404（不暴露存在性）；删除硬删除并级联消息 | 不变式 | A 读 B、A 删 B、已删除 ID | A9 |
| R4 | 聊天：服务端代理 DeepSeek，SSE 流式；模型白名单 `deepseek-flash`/`deepseek-v4-pro`；四种模式提示词**只在服务端定义**；完成后落库 assistant 消息与 usage | 不变式 | 非法模型、上游 401/402/429/5xx、客户端中途断开 | A10–A13 |
| R5 | 配额：默认每日 30 条、每月 1,000,000 token；管理员可按人覆盖（NULL=默认，-1=不限）；超限返回 429 + 可读原因 + 重置时间；日次数在调用上游前原子占位，避免并发超发 | 参数 | 第 31 条、token 超限、管理员改额度、并发双击 | A14–A16 |
| R6 | 错误统一信封 `{code,message,details,request_id}`；非 2xx 必带可读中文；前端显示原因与下一步，不显示 `[object Object]` | 不变式 | 422、401、429、502、断网 | A17 |
| R7 | 数据：SQLite 持久化到挂载卷；用户隔离；管理员 UI/API 不提供正文读取；备份可在演练库恢复 | 不变式 | 重建容器、备份恢复、越权查询 | A18 |
| R8 | 部署：独立容器；`/ZZYProj/` 下所有请求命中 `zzy-proj`，**不得误打主站 `/api/*`**；回滚一条命令到上一镜像；摘除 nginx location + 停容器即下线 | 不变式 | 刷新、直达 `/ZZYProj`（无斜杠）、旧页面缓存、主站接口回归 | A19–A21 |
| R9 | 邮件 fail closed：未配置 SMTP 时注册接口 503 且不写验证码；支持 465 SSL 与 587 STARTTLS | 不变式 | 未配置、错误授权码、超时 | A4、A22 |
| R10 | 管理操作写审计表（禁用/额度/角色）；初始管理员由 `ZZY_ADMIN_EMAILS` 指定；无管理员时管理接口全拒绝 | 不变式 | 非管理员、无管理员、管理员自降级 | A23 |
| R11 | 修改密码：必须验证当前密码；新密码 ≥8 位且不能与当前相同；成功后旧密码立即失效；管理员可用 `create_user.py --reset` 兜底 | 不变式 | 错误旧密码、新旧相同、过期 token | A24 |

## 5. 数据字典

| 名称 | 取值/结构 | 说明 |
| --- | --- | --- |
| `user.role` | `user` / `admin` | 初始管理员由环境变量指定 |
| `user.disabled` | `0` / `1` | 1 时登录与所有鉴权请求拒绝 |
| `user.daily_limit` | `NULL` / `-1` / 正整数 | NULL=默认 30；-1=不限 |
| `user.monthly_token_limit` | `NULL` / `-1` / 正整数 | NULL=默认 1,000,000；-1=不限 |
| `conversation.id` | UUID | 永不复用 |
| `message.role` | `user` / `assistant` | 失败轮次不写 assistant |
| `model` | `deepseek-flash` / `deepseek-v4-pro` | 白名单之外 400 |
| `usage.day` | `YYYY-MM-DD`（Asia/Shanghai） | 日次数与 token 聚合 |
| 验证码 | 6 位数字，哈希存储 | 10 分钟 TTL，最多 5 次尝试 |
